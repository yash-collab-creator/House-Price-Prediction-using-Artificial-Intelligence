# House Price Prediction using Artificial Intelligence

## Objective
Predict the approximate price of a house from its area using a simple Machine Learning model.

## AI Technique
Linear Regression.

## Requirements
Python 3.x
scikit-learn

Install:
pip install scikit-learn

## Run
python house_price_prediction.py

## Example
Enter house area in square feet: 1200
Estimated house price: ₹48.00 lakh

## Important
The dataset is intentionally tiny for academic demonstration. It is not suitable for real property valuation.
